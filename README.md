# SHOP.CO

Ek multi-page fashion e-commerce website — Bootstrap 5 aur HTML/CSS se 
banaya, real-world e-commerce UI patterns practice karne ke liye.

## Live Demo
[[LIVE_LINK]](https://sudias69.github.io/Shop.Co/)

## Pages
- **Home** — hero section, promo banner, featured products
- **Casual (Category)** — product listing with filters (price, colors)
- **Product Detail** — individual product page with details and reviews
- **Cart** — shopping cart page with product summary

## Features
- Fully responsive multi-page layout
- Filter sidebar (price, colors) on category page
- Product detail layout with ratings & reviews section
- Bootstrap 5 grid-based product cards

## Tech Stack
HTML, CSS, Bootstrap 5
